# Expense Tracker

A command-line Expense Tracker built with Python and SQLite to record, manage, and analyze personal expenses.

## Features
- Add, view, update, and delete expense records
- View total spend across all expenses
- View spend grouped by category
- View monthly spend summary

## Tech Stack
- Python
- SQLite (via Python's built-in `sqlite3` module)

## How to Run
1. Clone this repository
2. Run `python main.py`
3. Follow the on-screen menu to add, view, update, or delete expenses, and view spend reports

## What I Learned
- Writing SQL queries (INSERT, SELECT, UPDATE, DELETE, GROUP BY) from within Python
- Structuring a Python project with separate modules (`database.py`, `main.py`)
- Building a simple, functional command-line interface
